# Assumptions register

Every assumption the solution relies on about the upstream, the environment or the requirements. Code and tests
that rely on one cite its id in a comment (for example `// ASM-10: …`). Decisions are in [`adr/`](adr/); findings
(F-xx) are in [`CODE-ASSESSMENT.md`](CODE-ASSESSMENT.md).

Status values:

- **verified against the original backend (date)**: observed on the original Platzi backend run locally from its
  public source;
- **verified against the mock**: covered by the contract tests of our upstream mock;
- **unverified**: a reading of the task, a scope choice or a deployment premise.
